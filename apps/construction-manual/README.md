# 工事の手引き｜電気設備工事マニュアル

ログイン不要のスマートフォン・タブレット用マニュアル。工程・工種・用語の検索と、端末内に保存する工事記録を提供します。既存の工事管理アプリとは別のアプリです。

## 閲覧と記録

- 24章、10工種、用語集、39ページの基本解説PDF・随意契約の追加編PDF・26ページの印刷用管理票。
- 工事件名ごとに工程チェック、提出書類の状況・今回の期限・版、数量単価根拠・協議・変更・是正等のメモ。
- 記録はこのサイトのブラウザー内（localStorage）へ保存。アカウント・外部送信・端末間自動同期はありません。
- 保存ファイルをJSONで書き出して引継ぎ。読込は既存工事を保持して追加し、同一IDも別工事として追加します。
- 共用端末での閲覧、ブラウザーデータ削除、保存ファイルの取扱いに注意。個別契約の正式承認・検査・積算を代替しません。

## ホーム画面・オフライン

初回はHTTPS配信のURLへ接続し「オフライン利用の準備完了」を待ちます。iPhone・iPadはSafariの共有から「ホーム画面に追加」、Androidはブラウザーのメニューから追加できます。保存後は本文・PDFもオフライン閲覧できます。更新は「更新を確認」→「新版を開く」で適用し、工事記録は保持します。

## 配布と確認

`python3 apps/construction-manual/build.py` で、記録を含まない `offline-site.zip` を作成します。専用サブディレクトリへ中身をHTTPS配信してください。既存GitHub Pages公開ワークフローでは `/manual/` に配置します。新規Cloudflareプロジェクトや認証設定は変更しません。

- 構文：`node --check apps/construction-manual/app.js`
- 内容：`python3 apps/construction-manual/tests/content_test.py`
- ブラウザー：`node apps/construction-manual/tests/browser.cjs`（Playwright・Chromiumが必要）

ブラウザーテストはスマホ・タブレット幅、検索、保存・復帰、容量不足、JSON引継ぎ、不正保存データ、オフラインPDF、更新時の記録保持を確認します。iOS実機のホーム画面への追加と長期保存挙動は実機で確認してください。

## 随意契約と資料ガイド（1.2）

添付「入札不調時の随意契約 手続きマニュアル」（令和8年8月12日、5頁）を根拠に、応札なし／不落・再入札の条件確認、第一段階（発注伺い）、見積合わせ、第二段階（契約締結伺い）を追加。資料作成時点の記載と現行法令・規程・今回契約の確認を分け、見積期間や決裁金額を自動判定しません。

「資料から調べる」で10資料の内容・確認場所・版・注意点と参照ページを案内し、関連章にも資料カードを表示します。提供されていない約款・今回案件の資料を確認済みと扱いません。公式サイトの現行内容は実行環境の接続403により作成時照合未了です。

原本PDFは利用者が端末で選んだ場合だけ固有IndexedDBへ保存。公開パッケージや工事JSONに原本を含めず、サーバー送信なし。確認した参照版はSHA-256一致を確認し、参照ページを開きます。別版・非PDFは既存登録を保持して拒否。Safari等でPDFページ指定が効かない場合は閲覧側で該当ページを選びます。別端末へは原本も別途引き継いでください。

随意契約の12チェックは工事ごとに任意で追加し、通常の71チェックと既存記録は維持します。追加を外しても入力済みチェックを消しません。

追加検証：`node apps/construction-manual/tests/procurement.cjs`。原本テストには生成した架空PDFを使い、利用者の原本をテスト成果物や公開物に収録しません。追加編PDFの再生成は `node apps/construction-manual/scripts/render_procurement_pdf.cjs` → `python3 apps/construction-manual/scripts/finalize_procurement_pdf.py`（Playwright・Chromium・PyMuPDFのある開発環境のみ）です。

## 仕様書・基準の版管理（1.3）

指定された5分類を資料ガイドへ追加。正式名称・対象編・発行主体は原本で確認し、原本未受領・公式未照合の年度を最新版として作りません。`latestRelease` は確認済みの版、公表日、確認日、公式URL、変更概要を今後記載する枠、`releaseHistory` は案内版の更新履歴です。アプリの更新確認と公式資料の常時自動監視は別で、自動巡回はありません。

利用者は年度・版を付けてPDFを端末に複数保存できます。IndexedDBは既存名を維持してversion 2へ更新し、filesを保全してeditionsへ移行。異なる原本を登録しても旧版を削除しません。版ごとの明示削除のみ行えます。

「記録」→「適用資料」で、契約・特記仕様等から確認した原本を選び、工事にSHA-256と版名・指定根拠を保存。新しいPDF・アプリ案内版が来ても変更しません。JSONには適用情報だけを含め、原本なしの引継ぎは情報を保持して原本未登録と表示します。既存チェック・提出・メモのデータ版1は継続。

検証：`node apps/construction-manual/tests/editions.cjs`。旧DB移行、2版保存、公式案内更新時の適用版固定、1版だけの削除、JSON引継ぎとオフラインを検証します。
