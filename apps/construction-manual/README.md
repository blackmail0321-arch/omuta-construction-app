# 工事の手引き｜電気設備工事マニュアル

ログイン不要のスマートフォン・タブレット用マニュアル。工程・工種・用語の検索と、端末内に保存する工事記録を提供します。既存の工事管理アプリとは別のアプリです。

## 閲覧と記録

- 21章、10工種、用語集、39ページの解説PDFと26ページの印刷用管理票。
- 工事件名ごとに工程チェック、提出書類の状況・今回の期限・版、数量単価根拠・協議・変更・是正等のメモ。
- 記録はこのサイトのブラウザー内（localStorage）へ保存。アカウント・外部送信・端末間自動同期はありません。
- 保存ファイルをJSONで書き出して引継ぎ。読込は既存工事を保持して追加し、同一IDも別工事として追加します。
- 共用端末での閲覧、ブラウザーデータ削除、保存ファイルの取扱いに注意。個別契約の正式承認・検査・積算を代替しません。

## ホーム画面・オフライン

初回はHTTPS配信のURLへ接続し「オフライン利用の準備完了」を待ちます。iPhone・iPadはSafariの共有から「ホーム画面に追加」、Androidはブラウザーのメニューから追加できます。保存後は本文・PDFもオフライン閲覧できます。更新は「更新を確認」→「新版を開く」で適用し、工事記録は保持します。

## 配布と確認

`python3 apps/construction-manual/build.py` で、記録を含まない `offline-site.zip` を作成します。専用サブディレクトリへ中身をHTTPS配信してください。既存GitHub Pages公開ワークフローでは `/manual/` に配置します。新規Cloudflareプロジェクトや認証設定は変更しません。

- 構文：`node --check apps/construction-manual/app.js`
- 内容：`python3 apps/construction-manual/tests/content_test.py`
- ブラウザー：`node apps/construction-manual/tests/browser.cjs`（Playwright・Chromiumが必要）

ブラウザーテストはスマホ・タブレット幅、検索、保存・復帰、容量不足、JSON引継ぎ、不正保存データ、オフラインPDF、更新時の記録保持を確認します。iOS実機のホーム画面への追加と長期保存挙動は実機で確認してください。
