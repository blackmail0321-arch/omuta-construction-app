# 電圧降下ノート

単相2線100V/200V、平衡三相3線200Vの当該区間の電圧降下を即時計算する、ログイン不要の端末内Webアプリ。片道配線距離（立上り・下り・余長を含む）、Aまたは機器入力kW、遅れ力率、銅線サイズまたは製品R/Xを指定。ΔV・降下率・機器側電圧の概算、任意の目標との比較、目標に達する距離、サイズ別比較と条件付きコピーを表示。既存Pagesの `/voltage-drop/` へ配信します。

## 計算条件

単相2線：ΔV ≈ 2 I L(R cosφ + X sinφ)/1000。平衡三相3線：ΔV ≈ √3 I L(R cosφ + X sinφ)/1000。Lは片道m、R/Xは電線1条のΩ/km。降下率はΔV/電源電圧×100、機器側電圧はV−ΔV（近似）。線間電圧200Vの三相で100V相電圧として計算しません。単相100Vは2線の分岐回路を想定し、単相3線幹線の中性線・不平衡を含みません。進み力率は対象外。

概算モデルは、ρ=0.0178 Ω・mm²/mを**利用者が変更できる仮定値**としてR=1000ρ/A、X=0。メーカーの製品値、温度・交流特性を確認した値ではありません。数式は電線1条のR=ρL/Aと、回路の線路インピーダンスによる近似電圧降下から計算します。係数・製品表や法定許容率を転載・自動確定しません。初期の目標2%も比較のための仮の値で、規程を根拠とする適合判定ではありません。

製品R/Xモデルの初期R=3.4、X=0.08Ω/kmは入力例。使用する製品・周波数・敷設配列・運転温度に合うメーカー値に置き換えてください。温度補正は自動では行いません。このモードではサイズ別比較を出さず、各製品値を変えて比較します。

消費電力からの換算はI=P/(V cosφ)、三相I=P/(√3 V cosφ)。Pは**電気入力**kWで、軸出力を直接入力しません。単線mm径はπd²/4で面積へ換算、sqは公称mm²で、同じ数字として扱いません。

上流の降下・接続部・始動電流変動は含まず、全負荷を末端に集中させた当該区間の近似。分岐負荷・単相不平衡・詳細な電線選定・許容電流・保護協調の計算は対象外。大きい降下率では近似精度が悪くなり、ΔV>=Vなら機器側電圧を「算出範囲外」と表示します。サイズ比較は電圧降下だけで、採用を推奨・確定しません。

## 配布・保存

`node tests/core.cjs` と `node tests/browser.cjs` で検証。`python build.py` で依存なしのsite/とoffline-site.zipを生成。初回オンラインでService Workerに保存後、オフライン計算可能。最後の条件だけを独立localStorageキー`voltage-drop-note.settings.v1`へ保存し、他アプリの記録・キャッシュは削除しません。条件・結果の外部送信なし。コピーできないブラウザは選択可能な文章を表示します。

## アイコン

電験アプリと形で区別できるよう、雷を廃止し「オレンジ地・白いV・紺の下降矢印」に変更。生成原本はicon.png、配信用192/512pxはicons/に保持。ヘッダー・favicon・Apple touch・Web App Manifestを同じ図案へ統一し、配信ファイル名は内容識別子付きにします。既存iPadのホーム画面アイコンは自動で変わらない場合があります。Safariで更新したページを開き、共有→ホーム画面に追加で新しいショートカットを作ってください。計算条件やブラウザデータを消す必要はありません。
