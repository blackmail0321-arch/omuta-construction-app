# 聖羅とぱっと計算

％の金額、％/割の割引き・割増し、全体に対する割合、増減率、割引き/割増し前の元値を、数値入力で即時計算。入力した値を使った途中式・3段階の説明・割合バー、聖羅名義の案内吹出しを表示します。人物画像は利用者からこのトークへ添付されたものを反映する予定で、未添付時は中立の星アイコンを表示。別トークのキャラクター画像を取得済みとは扱いません。

計算はBigInt有理数で小数入力から正確に保持。途中で丸めず、表示時だけ小数4桁（四捨五入）または整数への四捨五入/切捨て/切上げを適用。1割=10%、2割5分=25%として2.5割を入力可能。単位切替は同じ割合になるよう20%↔2割へ変換。％入力6桁を割へ変換した時の精度を保つため、割のみ小数7桁に対応。金額・数値は0〜1兆・小数6桁まで。全角と正しい3桁区切りカンマを許容し、空欄・不正入力・分母0・100%引きの逆算は説明付きで停止。100%超の割合・割増しは許容します。連続割引きは一回ずつ計算し、単純に率を足さない説明を掲載。

キャラクターの説明は決められた文章に実際の計算値を差し込み、外部AIやAPIは使いません。数値・単位・表示設定・モード別入力だけを独立localStorageキー`seira-percent.inputs.v1`へ保存し、外部送信なし。コピーできない場合は選択可能な文章を表示します。実際の税額等の端数処理ルールを自動判断しません。

`node tests/core.cjs` / `node tests/browser.cjs`、`python build.py`。依存なしのPWA、専用キャッシュの範囲でオフライン対応。既存Pagesの `/seira-percent/` へ配置します。他アプリの入力やキャッシュは削除しません。
