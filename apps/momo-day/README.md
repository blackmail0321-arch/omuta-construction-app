# ももと いっしょ

桃ちゃんと「もじ・すうじ・よてい」を練習する、タブレット向けの端末内保存PWAです。娘さん本人が使う画面は大きいボタン・絵・短い言葉にまとめ、設定や記録の管理は保護者用画面に分けています。初期データに個人のお名前・予定・診断情報は含みません。

## 初めて使う

1. HTTPS公開URL `/momo/` をSafariで開き、保護者が暗号化用のパスフレーズを設定します。16文字以上・6種類以上の文字が必要です。忘れると復号できません。
2. 「おうちのかた」→ボタン3秒長押しで設定を開きます。パソコンではEnter/Spaceの長押しも使えます。この操作は誤操作防止であり、本人認証ではありません。
3. 名前の読み・練習する文字・音声を設定します。初期は「あ・い・う」と1〜10。数字0も保護者が追加できます。基本ひらがな46文字（50音表の現代仮名、濁音・半濁音は未対応）と数字0〜10を用意しています。
4. 音声を試します。端末内の日本語音声のみを使用し、なければ読み上げを止めて案内します。Safari/iPadの日本語音声の追加・音量を確認してください。音声の実機動作は端末ごとに確認が必要です。
5. オフライン準備完了を待ってホーム画面へ追加し、アイコンから一度オンラインで開きます。その後、通信を切って再起動・音声を確認してください。端末内の音声がない場合、オフラインで音声は利用できません。

## 文字・数字

- 「きく」：大きい文字をタップして、ゆっくり読み上げ。数字は5個ずつまとめた丸の数も表示。名前の読みは別ボタンで繰り返せます。
- 「えらぶ」：音声を聞いて2〜3候補から選びます。違った場合も罰や減点表示はなく、もう一度聞いて選べます。保存するのは初回回答だけです。
- 「かく」：指・Apple Pencil等で書ける枠、字形・始点番号のお手本、消す・一画戻す、音声でお手本を聞くボタンがあります。ペンの描画中は他の指の入力を受け付けません。
- 書いた後の約2秒、または「かいたもじをきく」で、実際の線と参照字形を端末内で比較し、読み取り候補を読み上げます。お題をそのまま正解として読み上げる仕組みではありません。候補から本人・保護者が確認できます。書いた線は保存・送信しません。
- 読み取りは字形の近さに基づく試作です。似た文字、崩れた字、書き方・書き順の違いでは間違います。正字・発達・発音の判定には使えません。発音の録音・評価機能はありません。

## 成長に合わせる仕組み

「えらぶ」の各文字で直近5回答のうち初回正解4回以上（最低4回、最後は正解）を目安に、選択中の全文字が条件を満たしたら次の文字を1つ追加します。1回の練習で追加は1つまで。苦手なときは選択肢を2つへ減らします。手書き候補の確認・発音は進級の根拠にしません。保護者が自動追加を止めたり、文字を個別に選び直したりできます。これは練習内容の段階調整であり、アプリ本体・AIモデルを自動更新する機能ではありません。

## 絵で見る予定

保護者が日付を選び、起床・ごはん・歯磨き・着替え・学校・トイレ・遊び・練習・お風呂・おでかけ・休憩・就寝の絵を最大12個まで並べます。言葉・時刻は任意で設定でき、順序変更・削除・前日コピーができます。「予定を保存」で確定します。

本人画面は今日の「いま」「つぎ」と絵の並びを表示します。未完了の先頭だけ押せて、「できた？」→「できた」で完了します。「まだだよ」で戻れます。誤って完了した場合は1つ戻せます。時刻の遅れ判定・自動通知はしません。

## 保存と公開

記録・名前・予定は端末内で暗号化します。自動同期なし。保護者設定から暗号化バックアップを保存し、別の端末で作成時のパスフレーズを入力して復元できます。復元前には現在の状態をバックアップ・暗号化復元用コピーとして保持します。30分無操作・画面を離れて30秒以上で再ロックし、未保存の設定・予定・書いた線を破棄します。

既存の予定表・貯蓄・体重アプリとは保存領域・オフラインキャッシュを分けます。既存の手動GitHub Pagesワークフローで `/momo/` へ公開します。公開プログラムに個人の記録は入りません。

ビルド：`python3 apps/momo-day/build.py`。生成物は空データの`index.html`、`service-worker.js`、`offline-site.zip`、`momo.zip`。参照字形はKanjiVG（CC BY-SA 3.0）。出典・ライセンスは `vendor/STROKES-LICENSE.md`。外部ライブラリや認識APIは不要です。

## 検証

`node apps/momo-day/tests/core.cjs`、`node apps/momo-day/tests/browser.cjs`、`node apps/momo-day/tests/recognition.cjs`、`node apps/momo-day/tests/security-offline.cjs`。Playwright/Chromiumを使用。音声は端末内音声のAPI呼び出しをスタブで検証しており、実際のiPadの声・Apple Pencil・本人の手書きは実機で確認する必要があります。参照57字形の一致は確認していますが、一般の手書きの認識精度を示すものではありません。
