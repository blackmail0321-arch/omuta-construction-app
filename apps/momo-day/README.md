# ももと いっしょ

桃ちゃんと「もじ・すうじ・よてい・カレンダー」を練習する、タブレット向けの端末内保存PWAです。娘さん本人が使う画面は大きいボタン・絵・短い言葉にまとめ、設定や記録の管理は保護者用画面に分けています。初期データに個人のお名前・予定・診断情報は含みません。

## 初めて使う

1. HTTPS公開URL `/momo/` をSafariで開き、保護者が暗号化用のパスフレーズを設定します。16文字以上・6種類以上の文字が必要です。忘れると復号できません。
2. 「おうちのかた」→ボタン3秒長押しで設定を開きます。パソコンではEnter/Spaceの長押しも使えます。この操作は誤操作防止であり、本人認証ではありません。
3. 名前の読み・練習する文字・音声を設定します。初期は「あ・い・う」と1〜10。本人の画面の「もじをえらぶ」「すうじをえらぶ」から、好きなものを直接選べます。数字は0〜100までで、「0〜10」「11〜20」…「91〜100」の範囲ボタンで切り替えます。基本ひらがな46文字に、濁音・半濁音25文字、小さい文字・長音10文字、拗音33組を追加し、数字0〜100を用意しています。「あ〜ん」「が・ぱ」「ゃ・っ」「きゃ・しゅ」で切り替えます。
4. 音声を試します。端末内の日本語音声のみを使用し、なければ読み上げを止めて案内します。Safari/iPadの日本語音声の追加・音量を確認してください。音声の実機動作は端末ごとに確認が必要です。
5. オフライン準備完了を待ってホーム画面へ追加し、アイコンから一度オンラインで開きます。その後、通信を切って再起動・音声を確認してください。端末内の音声がない場合、オフラインで音声は利用できません。

## 文字・数字

- 「きく」：大きい文字をタップして、ゆっくり読み上げ。数字は5個ずつまとめた丸の数も表示。名前の読みは別ボタンで繰り返せます。
- 「えらぶ」：音声を聞いて2〜3候補から選びます。違った場合も罰や減点表示はなく、もう一度聞いて選べます。保存するのは初回回答だけです。
- 「かく」：指・Apple Pencil等で書ける枠、字形・始点番号のお手本、消す・一画戻す、音声でお手本を聞くボタンがあります。ペンの描画中は他の指の入力を受け付けません。
- 書いた後の約2秒、または「かいたもじをきく」で、実際の線と参照字形を端末内で比較し、読み取り候補を読み上げます。お題をそのまま正解として読み上げる仕組みではありません。候補から本人・保護者が確認できます。書いた線は保存・送信しません。
- 読み取りは字形の近さに基づく試作です。似た文字、崩れた字、書き方・書き順の違いでは間違います。正字・発達・発音の判定には使えません。発音の録音・評価機能はありません。

## 好きな文字・自由書き・足し算

「もじをえらぶ」は50音表と濁音・半濁音・小さい文字・拗音の切り替え、「すうじをえらぶ」は0〜100を10ごとの範囲に分けた一覧です（最初だけ0〜10）。全数字を一度に並べず、範囲を押してから数字を選びます。保護者の数字設定も同じ範囲ごとに開けます。保護者のおすすめ設定とは別に、本人が好きな文字・数字を選んで聞く・選ぶ・書く練習ができます。数字11〜100のお手本は、0〜9の参照字形を横に配置したものです。

「じゆうにかく」はお題もなぞるお手本もない白紙です。文字は1文字ずつ、数字は0〜100の範囲で書き、候補を確認して聞けます。単語・文章・絵の自動認識はしません。線自体は自由に書け、保存しません。

「すうじ」→「たしざん」で、色の違う丸を数えながら答えを選べます。最初は1＋1、次の問題は答えが5までのやさしい範囲。「すうじをえらぶ」で足す2つの数をそれぞれ0〜10から選べます（答えは0〜20）。「いっしょにかぞえる」でゆっくり数えます。初回回答だけを暗号化して直近10問まで保存し、再挑戦で履歴を水増ししません。足し算は文字の自動追加条件には使いません。

## 数字のミニゲーム

ホームの「ミニゲーム」（または「すうじ」→「ミニゲーム」）から、桃ちゃんと4種類の遊びができます。

- 「すうじあわせ」：数字のカードと同じ数の丸のカードを1枚ずつタップ。数字から・丸からのどちらでも遊べます。初期は1〜10の10組（数字10枚と丸10枚）です。2組・3組にも減らせます。10組のときは、選んだ数がスクロール中も見える帯と「えらびなおす」を用意しています。合ったカードには「✓できた」を表示し、間違えた場合はその場で試し直せます。
- 「ババぬき」：桃ちゃんと2人で遊ぶ数字カード版です。初期は1〜10のペア20枚＋ジョーカー1枚（計21枚）で、最初に本人11枚・桃ちゃん10枚の手札を省略せず表示します。「ペアをそろえてはじめる」を押してから初めのペアを出し、本人が桃ちゃんの裏向きカードを1枚選びます。配った時の枚数と、ペアを除いた後の手札枚数を画面で区別します。通常の1ジョーカールールでは総数が奇数になります。少なくする場合は1〜3（計7枚）・1〜5（計11枚）にもできます。本人の手札に同じ数字がそろうと自動でペアになります。次は「もものばんへ」を押すと、桃ちゃんが本人のカードを無作為に1枚引きます。どちらかの手札がなくなると終わり、残った1枚はジョーカーです。ジョーカーは星の絵で、怖い演出・罰・勝敗履歴はありません。相手の手札は終了まで裏向きに表示します。
- 「しんけいすいじゃく」：「すうじあわせ」「もじあわせ」を切り替えられます。裏向きのカードを2枚めくり、同じ数字・文字のペアを探します。文字版は基本ひらがな46文字からゲームごとに重複なくランダムに選び、各文字を必ず2枚ずつ入れます。「もういちど」や枚数の変更でも文字を選び直します。初期は5組10枚で、2組4枚・10組20枚も選べます。違うカードは自動で伏せず、本人が覚えてから交代ボタンで進めます。めくった数字・文字を音声でも確認でき、時間制限・減点はありません。
- 「じゅんばん」：1から小さい順にカードを押して並べます。1〜3、1〜5、1〜10から選べ、「つぎは」の数字を常に表示します。

時間制限・減点・ランキング・自動的な難易度上昇はありません。「もういちど」で同じ難しさから新しい並びにできます。「おしまい」でいつでもホームへ戻れます。ゲームの途中状態はメモリだけで、ゲーム切り替え・再起動・ロック等でリセットします。既存の文字・数字の習熟度や予定は変更せず、ゲームの結果を発達評価や進級に使いません。初回準備後はオフラインでも遊べます（音声の可否は端末の日本語音声によります）。

## 声をかわいく・聞き取りやすくする

保護者の「練習と音声」で声を試聴し、保存できます。「かわいく・やさしく」はピッチ1.15の少し高い声、「はっきり」はピッチ1.0。速さは3段階、「ひとつずつ」の文字間は350/650/1000ms。初期はゆっくり・650msです。「かわいく・ゆっくりにする」でおすすめ設定を試せます。

声そのものは端末内の日本語音声を使い、外部の合成音声APIへ送信しません。声の種類・声質・ピッチ変更の反映はOS・音声エンジンによって異なります。可愛さや聞き取りやすさは実機で試聴して選んでください。専用の子どもの声や録音音声の追加ではありません。

## 好きな文字・数字を並べて聞く

「もじ」または「すうじ」→「ならべてきく」。カードを押した順に最大20個まで並びます。文字と数字を混ぜられ、カード単体の再生、ひとつ戻す、全部消すも使えます。

- 「ひとつずつきく」：文字・数字カードごとに間を空け、再生中のカードを強調します。「きゃ」は1組で選べます。小さい「ゃ」単体は「ちいさいや」のように説明して読みます。
- 「つなげてきく」：続く文字を単語として自然につなげます。「き」＋「ゃ」も「きゃ」にして読みます。拗音カードだけでも選べます。
- 数字カードは常に1枚ずつの数です。「1」「2」は「いち・に」、「12」のカードなら「じゅうに」。文字に続く数字も読み上げが区別できるように区切ります。
- 「ーのばす」：文字の種類にかかわらず、読みの文字画面から長音をすぐ追加できます。「カタカナ」→「ジ」「ュ」「ー」「ス」→「つなげてきく」で「ジュース」を再生できます。
- 「゛てんてん」「゜まる」：最後に並べた対応文字を「か→が」「は→ぱ」「きゃ→ぎゃ」のように変えます。完成した「が」「ぱ」「ぎゃ」も一覧で選べます。
- 「とめる」、画面移動、バックグラウンド移行、ロックで途中再生と次の文字の予約を停止します。

「キーボードでことばをいれる」を開くと、ひらがな・カタカナ・数字を20文字まで入力して並べることもできます。入力した内容で現在の並びを置き換えます。数字は1桁ずつのカードになり、範囲外の文字は受け付けません。カタカナは読みの文字並べだけに対応し、手書き認識の対象には追加していません。

並べた内容はメモリだけに保持し、再起動・ロックで消えます。履歴・バックアップには保存しません。手書き認識の対象は1文字または拗音1組であり、手書きの単語・文章を自動認識する機能ではありません。普通の文字と小さい文字は形が似ているため、候補から確認してください。

## 成長に合わせる仕組み

「えらぶ」の各文字で直近5回答のうち初回正解4回以上（最低4回、最後は正解）を目安に、選択中の全文字が条件を満たしたら次の文字を1つ追加します。1回の練習で追加は1つまで。苦手なときは選択肢を2つへ減らします。手書き候補の確認・発音は進級の根拠にしません。保護者が自動追加を止めたり、文字を個別に選び直したりできます。これは練習内容の段階調整であり、アプリ本体・AIモデルを自動更新する機能ではありません。

## 絵で見る予定

本人の「よてい」画面の「よていをつくる（おうちのかた）」→3秒長押しで直接編集画面を開けます。①日付→②絵を順番にタップ→③並びを確認→④保存、の4段階です。保護者が日付を選び、6つの切り替え（ふだん／たべもの／おでかけ／くらし／たのしみ／ぜんぶ）から38種類の絵を選んで、1日最大12個まで並べます。ジュース・買い物・公園・さんぽ・ラーメン・ハンバーガー・カレー・デイサービス・旅行のほか、水・おやつ・果物・電車・バス・病院・図書館・友だち・音楽・プール・運動・工作・映画などがあります。言葉・時刻は任意で設定でき、順序変更・削除・前日コピーができます。「この日の予定を保存」で確定し、「よていの画面へ戻る」で確認できます。「朝の例を入れる」で起床・ごはん・歯磨きの3つを試せますが、保存までは端末記録を書き換えません。言葉・時刻は「言葉・時刻を付けて追加する」を開いて指定します。

本人画面は今日の「いま」「つぎ」と絵の並びを表示します。未完了の先頭だけ押せて、「できた？」→「できた」で完了します。「まだだよ」で戻れます。誤って完了した場合は1つ戻せます。時刻の遅れ判定・自動通知はしません。

## カレンダーで確認

ホームの5つの入口は「もじ・すうじ・よてい・カレンダー・ミニゲーム」です。ミニゲームはホームの上段にある独立した大きな入口から直接開け、「すうじ」内の入口も引き続き使えます。「よてい」は今日の行動を進める画面、「カレンダー」は日曜日始まりの月表示・1週間表示です。前後の月／週、年月・日付の入力、「きょう」で移動できます。日付のカードに絵と予定数を表示し、タップしてその日の全予定を開きます。

カレンダーで選んだ日から「よていをつくる」へ進むと、その日付のまま保護者の編集画面へ移ります。保存後はその日の予定に戻ります。今日以外は閲覧専用で「できた」を付けません。未来の予定を誤って完了しないための仕様です。日付と予定は端末内の暗号化記録を使い、外部カレンダーとは同期しません。

手書き候補の音声は「あ」など文字の読みだけに変更し、「かな？」は読み上げません。候補であることは画面上で確認します。足し算の「＝」に続く助詞は発音が安定するよう「わ」の文字で音声に渡します。

## 保存と公開

記録・名前・予定は端末内で暗号化します。自動同期なし。保護者設定から暗号化バックアップを保存し、別の端末で作成時のパスフレーズを入力して復元できます。復元前には現在の状態をバックアップ・暗号化復元用コピーとして保持します。30分無操作・画面を離れて30秒以上で再ロックし、未保存の設定・予定・書いた線を破棄します。

既存の予定表・貯蓄・体重アプリとは保存領域・オフラインキャッシュを分けます。既存の手動GitHub Pagesワークフローで `/momo/` へ公開します。公開プログラムに個人の記録は入りません。

ビルド：`python3 apps/momo-day/build.py`。生成物は空データの`index.html`、`service-worker.js`、`offline-site.zip`、`momo.zip`。参照字形はKanjiVG（CC BY-SA 3.0）。出典・ライセンスは `vendor/STROKES-LICENSE.md`。外部ライブラリや認識APIは不要です。

## 桃ちゃんのホーム画面アイコン

ホーム画面・Safari用に、ピンク背景の桃ちゃんアイコンを同梱しています。iPad/iPhone用180・167・152pxと、PWA用192・512pxを用意し、旧アイコンのURLから切り替えています。公開後はアプリを更新してください。iPadの既存ホーム画面アイコンはOS側に保持されることがあり、自動で変わらない場合は保護者が先に暗号化バックアップを保存し、Safariで同じ公開URLを開いて「共有→ホーム画面に追加」で新しいアイコンを作ります。アプリやWebサイトの保存データを消す操作は不要です。追加したアイコン側で記録が空の場合は、バックアップから復元できます。

### 対戦ゲーム
「ミニゲーム」の神経衰弱は、数字・ランダムなひらがなの両方で桃ちゃんと対戦できます。ペアができた人は続けてめくり、違った場合に交代します。あなたは青、桃ちゃんはピンク。色に加えて名前・ペア数・勝敗も表示します。桃ちゃんは既に見えたカードだけを覚えて選びます。交代ボタンを押すまでカードを確認でき、時間制限はありません。

オセロはあなたが黒、桃ちゃんが白です。正規の8×8（64マス）で、置ける場所には○を表示します。桃ちゃんは合法手からランダムに選びます。置けない場合は自動パスし、両者が置けなくなると石の数で勝敗を表示します。8×8盤は小さい画面では盤の部分を横にスクロールできます。
ゲームの途中経過・勝敗は保存せず、学習の進級判定にも使いません。再起動・ロックで消えます。

画面下の「更新を確認」は常に表示します。通信できる状態で押すと、新しい版を確認し、確認後に更新できます。新しい版がない場合は「現在は最新です」と表示します。保存済みの学習記録・予定は保持します。

### CPU・人対人の切り替え
神経衰弱・オセロ・ババ抜きの上部にある「だれと あそぶ？」で「もも（CPU）と あそぶ」または「ふたりで あそぶ」を選べます。人対人は同じ端末を交互に使います。1ばんさんは青、2ばんさんはピンクで、番・得点・勝敗に名前も表示します。オセロは1ばんさんが黒、2ばんさんが白です。

人対人の神経衰弱はペアができた人が続けて2枚めくれます。違った場合は交代ボタンで次の人が自分でめくります。CPUも同じルールで、連続する番はボタンで2枚ずつ進めます。ババ抜きは交代時に両者の手札を伏せます。次の人に端末を渡してから、その人が「じゅんび OK」を押してください。自分の手札だけが見え、相手の裏カードを選んで引きます。画面を他のアプリへ切り替えた場合も手札を隠します。

相手を変更すると現在のゲームを終了し、新しいゲームを始めます。相手の選択・ゲーム途中の情報は端末内の一時状態のみで、再起動・ロックで消えます。別端末間のオンライン対戦ではありません。
