# iPad miniで使うための準備

## 現在の状態

iPad向けの静的Web版を準備し、768×1024／1024×768のタッチ端末エミュレーション、演習・採点・通信切断後の再読み込みを確認しました。**公開の承認を受け、GitHub Pagesへの反映を進めています。iPad実機のSafariでの確認は公開後に必要です。**

公開用ZIPはリポジトリの `downloads/denken-study-ipad-site.zip` です。公開予定の配置先は、既存のGitHub Pagesサイト内の `denken/` です。GitHub Pagesの有効化・権限・公開URLは公開時に確認します。

## iPad版で利用できるもの

- 収録済み問題の演習・採点・苦手復習・学習計画・時間制限付き模試。
- Safariの共有メニューからホーム画面への追加。
- 初回に保存が完了した後のオフライン演習。
- PCで書き出した学習記録の読み込みと、iPad側の記録の書き出し。

学習記録はiPad内です。PCとの自動同期、アカウント共有、クラウドへの記録保存は実装していません。

## 公開後の操作

1. 案内するHTTPSのURLを、iPad miniのSafariで開きます。
2. 「iPad Web版の使い方・保存状況」を開き、「オフライン保存済み」の表示を確認します。
3. Safariの共有ボタン（四角から上向きの矢印）→「ホーム画面に追加」→「追加」を押します。
4. 以後はホーム画面の「電験一種」アイコンから起動できます。
5. 設定・記録から学習記録を定期的に書き出します。端末の保存容量やSafariのデータ削除等で記録が消える場合があります。

PCから記録を引き継ぐ場合は、PCの「学習記録を書き出す」で保存したJSONをiPadへファイルとして渡し、iPad版の「学習記録を読み込む」で選びます。現在のiPad側記録は置き換わるため、先に書き出してください。

## AIと他年度取得について

この静的Web版では、AI接続と公式資料の追加取得を無効にしています。APIキー入力欄やPCセットアップ案内も非表示です。PCの `127.0.0.1` をiPadへ入力しても、PCのサーバーにはつながりません。

iPadでAIを使うには、APIキーを安全に保持するログイン付きのHTTPSサーバーを別途準備する必要があります。GitHub PagesだけではPythonのAI接続処理を実行できません。APIキーを公開HTMLやGitHubへ書き込んで公開しないでください。

現状のPCでの407プロキシ認証エラーも、別途管理担当者の正規設定が必要です。Web版を公開するだけで、この認証が解決するわけではありません。

## 公開前に確認すること

この公開案では、**教材（問題画像・PDFを含む）とアプリのプログラムは一般に閲覧できる状態になります**。利用者の学習記録やAPIキーは公開ファイルに含めません。非公開での利用が必要な場合は、公開前に認証付きの配信方法へ変更します。

公開操作は承認後に行います。専用ブランチへの保存は公開完了を意味しません。mainへの反映・公開ワークフローの実行・実際のURLの確認が別途必要です。

## 構成

`python3 scripts/build_app.py` → `python3 scripts/build_ipad_site.py` で生成します。追加パッケージは不要です。`web/` と `ipad-site.zip` は生成物としてGitでは無視します。

サービスワーカーは自身の配信パスに限定してファイルを保持し、他アプリのキャッシュや保存データを削除しません。APIへのリクエストは発生させません。

既存のPagesワークフローの下書きには、このZIPを既存サイトの `denken/` へ展開する3行だけを追加しました。既存アプリのビルド・配置は維持し、公開承認後、mainの電験アプリ更新に限定した公開トリガーを追加しています。既存の手動公開も維持します。
