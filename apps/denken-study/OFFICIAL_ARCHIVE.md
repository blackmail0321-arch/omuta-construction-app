# 電験一種・三種と毎日の追加

公開アプリは従来の `/denken/`。画面上部で電験一種／三種を選ぶ。三種は同じアプリの `/denken/third/` に切り替え、問題・正答・学習履歴・メモ・学習計画・バックアップを区別する。一種の既存保存キー `denken-one-study-v1` を変更せず、三種は `denken-three-study-v1`。異なる種別のバックアップは取り込まない。切替時に採点前の入力があれば確認する。

## 取得と配信

GitHub Actions `Publish apps and daily Denken update` が毎日21:00 UTC（日本時間翌朝6時）に実行される。GitHub側の混雑等で遅れる場合がある。PCやiPadを起動しておく必要はない。

- 一種：未収録の古い年度を新しい順に、1日最大2年度。
- 三種：1日最大1年度。同じ年度の上期・下期は公開済みの両方を同じ年度として扱う。未実施・未掲載の期は取得済みとしない。
- 同じ日本日付で再実行しても追加を重複しない。取得・検証失敗時は前の公開版を保持する。
- 原本は公式一覧の掲載リンクだけから取得し、各PDFの出典・年度・区分・科目・SHA256を保存する。古い形式などで採点を照合できない場合は原本閲覧として明記する。
- 公開一覧の最古まで到達したら、それ以上古い年度のURLを推測しない。掲載された既存年度に新しい期が加わった場合は、その年度の不足分を先に確認する。

`data/daily-status.json` に日本日付・追加年度・履歴を保存する。収集ジョブで確認したデータをmainへ保存し、同じワークフローの後段で最新mainをビルド・配信する。GITHUB_TOKENによるpushが別のワークフローを自動起動しない制約に依存しない構成とした。mainへの競合時はforce-pushせず停止する。

初回の追加は一種2022・2023年度、三種2026年度上期。既存の一種2024・2025年度と2026年度の添付教材を保持する。三種は初回66大問・80小問（選択問題を両方含む）。模試は理論・機械が問17/18から1問選択、電力・法規は必須問題を使い、各科目100点満点。時間の初期値は理論・電力・機械90分、法規65分。一種は従来の80点満点と問6/7の選択を維持する。

## 図解・会話

一種の既存4大問の詳細解説を保持。三種2026年度上期・理論問1（コンデンサ）と問2（点電荷の電位差）へ、各7コマの独自の会話・図解・確認クイズを追加。正答との対応と計算を検証する。未対応問題へ詳細な解説があるように表示しない。図解・独自予想問題・ネットからの詳しい引用・外部AI接続が、毎日の資料取得によって自動生成されるわけではない。三種の独自予想問題は未整備。

## 容量・保存・検証

原本PDFは必要なときだけ開き、初期表示やサービスワーカーの保存対象へ一括で含めない。年度ZIPは各種の新しい2年度だけを作り、古い年度は個別PDFで閲覧する。三種本体は約170KBで、一種の元の教材を三種起動時に読み込まない。学習者の記録・キーは公開ファイルへ収録しない。

親の一種サービスワーカーは自分のトップページだけにナビゲーションを返す。三種への初回切替を一種のキャッシュで上書きしない。キャッシュとマニフェストは各スコープで分離し、互いの学習記録を削除しない。

`tests/dual.cjs` は親サービスワーカーが動いた状態の種別切替、両記録・バックアップの分離、三種の正答と100点模試、図解の表示、確認クイズが試験記録を変更しないこと、幅390/768/1024を検証する。`tests/dual_test.py` は日次上限・同日再実行の無取得、原本の正答配点と模試100点、解説の物理計算を検証する。既存一種の採点・復習・模試・オフライン試験も維持する。実機SafariでのPDF表示・保存と、将来の定時実行の完了は現時点の実機試験結果ではない。
