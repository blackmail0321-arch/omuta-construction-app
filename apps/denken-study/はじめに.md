# 電験一種 学習ノート — はじめに

## 今回の更新後に最初に行うこと

1. 以前のアプリで「設定・記録」→「学習記録を書き出す」を実行します。
2. GitHubから新しいZIPを保存して、すべて展開します。
3. Windowsでは「セットアップして起動.cmd」を開きます。初回はアプリ専用のPython環境へPDF用部品を取得し、その後ブラウザを開きます。Python 3.10以上が必要です。
4. 新しい画面で「設定・記録」→「学習記録を読み込む」から以前の記録を引き継ぎます。ファイルを直接開く場合とサーバーから開く場合では、ブラウザの保存領域が異なります。
5. 「教材と出典」→「公式過去問・参考引用を取得する」を押します。お使いのPCから公式サイトへ接続します。取得・照合できたものだけを追加します。通信エラー時に追加できたと表示しません。
6. AIはAPIキー取得後に「設定・記録」→「AIへの接続設定」で入力し、「認証を確認して接続する」を押します。

APIキーをまだ持っていない場合は、手順6を後にして構いません。ChatGPTの有料プランとAPIの利用は別です。API提供元でのキー取得・利用枠の設定が必要です。このアプリがAPIキーを作成したり、支払設定を自動変更したりすることはありません。

画面に入力したキーは同じPCのローカルサーバーへ送り、指定モデルへの認証付き通信に成功した場合だけ、その起動中のメモリに保持します。ブラウザの学習記録や配布ファイルへ保存しません。画面を閉じるだけでなく、起動用ウィンドウを閉じてサーバーを終了すると失われます。接続解除ボタンでも消去できます。

この更新では接続・初期設定の操作を追加しましたが、作業環境での公式資料取得は引き続き403、実AIキーも未設定です。他年度・引用本文の追加や実AIでの解説生成を実証した更新ではありません。取得スクリプトの他年度への適合性、AIの応答品質には今後の確認が必要です。

## 今回追加した機能を使う

ZIP一式を展開してください。基本機能だけなら `index.html` を開けます。過去問・引用の取得とAI接続は、サーバー付き起動を使います。

- Windows：`アプリを起動.cmd` を開きます。AIキーを端末の入力欄で受け取る場合は `AIつきで起動.cmd`、ブラウザ画面で設定する場合は通常の起動後に「設定・記録」を使います。
- Mac：`アプリを起動.command` または `AIつきで起動.command` を使います。
- 起動にはPython 3が必要です。PDFを取得・照合する機能には `requirements-build.txt` のPyMuPDFも必要です。
- 起動後「教材と出典」→「公式過去問・参考引用を取得する」で確認を開始します。
- 通信と認証の状態は「設定・記録」→「AIの接続を確認する」で確認できます。

「AIつきで起動」のキー入力は画面に表示されず、そのプロセス内だけで使います。空欄ならAIなしで起動します。環境の安全な設定に登録したキーが利用できる場合は再入力しません。クラウド環境の認証設定が、ダウンロード先のPCに自動で引き継がれるわけではありません。

キーをチャットに貼る必要はありません。AI提供元の利用権限・料金は別途必要です。現時点ではクラウド環境のキーは未設定です。

通信許可が整うと、公式リンクからPDFを取得し、一次・一種・年度・科目を識別します。4科目の列を検出した正答表と問題冊子を照合し、問題番号・正答記号・配点合計が一致した科目を追加します。対応できないレイアウトは自動登録せず、エラーとして残します。この処理は2026年度の添付4科目で検証済みですが、未取得の他年度レイアウトへの適合を保証するものではありません。

引用は許可された参考サイトの記事本文から短く抽出し、記事名・URL・確認日とともに表示します。機械的に取得できたことと、その説明が個別問題に適切であることを区別し、適合性の未確認状態を表示します。引用文を独自説明として書き換えたり、未取得の文章を引用したと表示したりしません。

**現状の外部接続：公式・参考サイトはHTTPトンネル403、AIキーは未設定です。今回、他年度の教材や引用を実際に追加できたわけではありません。** 既存の演習・学習記録はそのまま利用できます。

## すぐに使う

`index.html`をダウンロードして、Chrome・Edge・Safariなどのブラウザで開いてください。基本の演習・採点・復習管理は、インストールや外部AIの契約なしで使えます。図・数式・原本PDFもファイル内に含めています。

1. 「設定・記録」で目標年度と1日の時間を確認します。初期値は令和9年度、平日・休日とも60分です。令和10年度へ変更できます。
2. 「科目別演習」でまず4科目に取り組み、自信の程度も記録します。
3. 採点後に正答と基礎説明を読み、「自分の言葉で説明する」に考え方を書きます。
4. 「苦手の復習」から、復習日になった問題・誤答・自信のない問題を解き直します。
5. 「本番模試」で時間制限付きの過去問、または独自予想演習に挑戦します。
6. 「設定・記録」→「学習記録を書き出す」でバックアップしてください。

スマートフォンでもブラウザで利用できます。ファイルアプリ内のプレビューが操作に対応していない場合は、ブラウザで開いてください。端末によってローカルHTMLの扱いが異なるため、端末実機での確認は未実施です。

## 収録したもの

- 添付の令和8年度（2026年度）一次試験：理論・電力・機械・法規、26大問・150小問。
- 添付の正答表と配点。正答記号が冊子の解答群に存在すること、配点合計、選択問題の扱いを確認しています。
- 26分野の独自の基礎説明。過去問の全小問に対する完全な解説ではありません。
- 独自の基礎確認問題24問。
- 独自の応用予想演習24大問・120小問。4科目それぞれ6大問・30小問・80点満点。類題を含みます。一種相当の難度校正・専門家による監修は未実施です。

合計294小問です。公式過去問と独自問題は、画面上で区別しています。

## 復習と学習計画

誤答は6時間後、自信のない正解は翌日、根拠を説明できる正解は連続正解に応じて1・3・7・14・30・60日後へ予定します。これは学習記録を使うルール方式です。外部AIが理解度を診断しているという表示はしません。

自動の学習時間は、演習画面を表示している時間の目安です。実際の集中度や理解を測定するものではありません。アプリ外の時間は学習計画から手動追加できます。

試験日は、公式日程を確認した後に自分で設定します。初期状態では空欄で、残り日数を推測しません。目標70%は独自の学習目標で、公式の合格点を示すものではありません。

受験準備の目安は、初見・時間内・解説なしの模試が3回、2年度以上あるときに科目ごとに評価する設計です。現在は1年度しかないため判定保留です。独自予想演習や既習問題の成績は準備判定に使いません。合格確率や合格保証ではなく、二次試験も対象外です。

## 保存について

チェック・解答・自信・メモ・復習予定・学習時間・模試・設定を、このブラウザの保存領域に保存します。アカウント登録や自動同期はありません。

同じブラウザで開いていても、ファイルの移動や名称変更で別の保存領域になる場合があります。端末変更前、ファイル移動前、更新前に学習記録を書き出してください。別端末では「学習記録を読み込む」で引き継げます。読み込みは現在の記録を置き換えるので、先に保存してください。

保存領域を使えないブラウザではエラーを表示します。プライベートモードは記録が残らない場合があります。

### 外部AIによる個別解説

接続処理は実装しましたが、認証情報がないため実サービスへの通信は未検証です。未接続でも基本機能は使えます。

環境設定に`DENKEN_AI_KEY`の要件を保存しました。APIキーの値はチャットに貼らず、安全な環境設定で登録してください。必要な接続先はapi.openai.comです。ブラウザ側へキーを渡しません。

接続する場合は同梱一式を展開し、Python 3.10以上で次を実行します。

```sh
python3 server.py --port 8031
```

ブラウザで同じ端末のポート8031を開きます。サーバーは127.0.0.1だけで待ち受けます。クラウド環境からの一般公開・スマートフォンへの配信や本番運用は行っていません。

`DENKEN_AI_KEY`はサーバー起動環境で設定してください。任意の`DENKEN_AI_MODEL`でモデルを変更できます（初期値gpt-5-mini）。モデル利用権限・料金・通信許可の確認が必要です。質問ボタンを押した場合だけ、対象問題の文章・図・正答と質問をAI提供元へ送ります。AI回答は生成説明として表示し、出典付き引用とは区別します。

## 構成・再生成

既存の工事アプリとは別のディレクトリに作成しています。元の工事アプリを変更していません。

- index.html：すぐ使える単一ファイル版
- app.js / core.js / style.css：画面・学習ロジック・デザイン
- assets/：添付PDFのコピー
- data/：抽出問題、独自問題、基礎説明、取得結果
- server.py / launch.py：ローカル配信、起動、AI接続、教材更新
- materials.py：追加PDFの分類・問題と正答の照合
- scripts/：生成と公式リンク取得
- tests/：採点・復習・画面・サーバーの検証

生成済みアプリとサーバーの使用には追加パッケージは不要です。PDFから再生成する場合だけPyMuPDFが必要です。

```sh
python3 scripts/build_bank.py
python3 scripts/write_content.py
python3 scripts/write_forecasts.py
python3 scripts/build_app.py
```

`build_bank.py`は同梱assetsから再生成します。別のアップロード元を使うときはディレクトリを引数に指定できます。build_bank.pyは2026年度用です。追加教材にはmaterials.pyの検出・照合処理を使います。他年度は形式判定と配点照合に通るものだけ登録します。
