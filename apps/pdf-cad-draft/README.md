# 図面の下書き

ログインなしでPDFを端末内で読み込み、黒背景で下図と編集線を表示する下書き支援アプリ。既存Pagesの `/pdf-cad/` へ配置します。アップロード図面や抽出成果は公開プログラムに含みません。外部AI、CDN、API通信を使用しません。

## 使い方
1. PDFを開き、ページを選ぶ（80MB・200ページまで、パスワード付き非対応）。
2. 必要なら範囲の対角2点を指定し、水平・垂直の直線を抽出する。
3. 抽出線はすべて未分類。線を複数選び、建物・照明・配線へ分類する。削除や直線・円の追記、25操作まで戻すことが可能。
4. 寸法の両端2点と実際の長さmmで縮尺を合わせる。別の既知寸法でも検証する。
5. 作業JSONとDXFを保存。作業JSONは下図画像・図形・縮尺を含み、端末間で再開できる。JSONは暗号化されていないので各自で保管する。
6. DXF R12をJw_cadで開き、確認してJWW保存する。DXFのレイヤーは BUILDING / LIGHTING / WIRING / REVIEW。黒背景はアプリ表示の設定でJw_cad本体へ強制しない。

## 限界・保存
線の候補抽出であり、壁や器具の意味は自動認識しません。文字、曲線、斜線、CAD寸法情報や回路情報は復元しません。円・配線は利用者が追記できます。元のスキャンの歪みや欠落は修正が必要です。抽出の最短長はPDF表示画像の画素で、実寸とは別です。

編集後は同じ端末・ブラウザのIndexedDBへ自動保存します。端末間同期・オフライン起動の保証はありません。終了前は「この端末に保存済み」の表示を確認し、別端末やデータ消去に備えて作業JSONも保存してください。DXFには下図画像を含みません。非表示のレイヤーも全てDXFへ出力します。実寸版のDXFは縮尺未設定では止め、確認用DXFとは区別します。推測で実寸を決めません。

Python `build.py` で配信用siteとZIPを生成します。既存savings-ledgerのPDF.js 6.5.438と同じ資産・ライセンスを同梱します（正確な版は同アプリvendor/VERSIONS.json参照）。ブラウザテストとDXF再読込で検査し、Jw_cad実機とiPad実機の検証は別途必要です。

## 解像度と操作ガイド

解像度は標準2400／高精細3600（初期）／最高4800画素まで。総画素1600万を上限にし、縦横比で実際の大きさは変わります。解像度を上げても原本のスキャン以上の情報は復元しません。原本PDFを開いている間は再描画で解像度を変更し、編集図形・レイヤー・実寸の長さを維持します（画素丸めによる下図とのずれは1画素程度、原点位置は変わる場合がある）。変更時は戻す履歴をリセットします。保存作業のみではPDFがないため高精細化を止め、原本の選択を案内します。作業JSONの互換性は維持、読込上限100MB・下図90MB以内・1650万画素まで。

画面先頭の5段階ガイドと「操作する場所を表示」で、各操作の説明とボタン位置を確認できます。現在の操作モードと2点指定の途中経過も図面の上に表示します。

## Pencil・指による範囲選択

図面の近くの「四角で囲む」「投げ縄で囲む」からPencilまたはマウスでドラッグし、離して確定します。範囲に触れる図形を選ぶ方式です。非表示レイヤーは対象外。「選択を入れ替える／追加する／選択から外す」で調整できます。選択後は近くの「建物へ／照明へ／配線へ」で一括分類します。抽出範囲もドラッグ指定に変更しました。

指は標準で図面の移動、2本指は拡大縮小です。「指でも囲む」をオンにすると指1本でも範囲選択や描画指定ができます。Pencil入力中の指は図面操作から除外します。途中キャンセルでは選択を確定しません。範囲プレビューは毎フレーム更新、ピンチ中は全図形を再構築せず表示倍率だけを更新します。ブラウザのpen/touch入力で動作を検証し、Apple Pencil・iPad実機での遅延やパームリジェクションの確認は残ります。

検証は `node tests/core.cjs`、`python3 build.py`、`node tests/browser.cjs`、`node tests/gestures.cjs`。ブラウザ検証はPlaywright/Chromiumを使用し、合成PDF生成にはPyMuPDFが必要です。任意の非公開検証PDFは環境変数CAD_TEST_PDFで指定でき、公開物には収録しません。

## 原本画像を囲んで切り出す

線の抽出前でも「四角で囲む」「投げ縄で囲む」または抽出範囲指定で囲みを残し、「囲んだ範囲だけ残す」を押せます。囲みの枠はペンを離しても維持し、保存JSONでも再開できます。切り出しでは下図を実際にクロップし、投げ縄の外側は白くマスク（黒背景表示では黒）にします。直線は範囲の境界で切り分け、内側の区間だけを残します。円は完全に含まれるものだけを残し、切り口にまたがる円は除外します。元ファイル自体は変更しません。

切り出した作業はJSONに保存して再開できます。縮尺の係数は保持しますが座標の原点は切り出し位置に変わります。抽出範囲・画像・図形を含めて「ひとつ戻す」で復元できます（履歴は最大25操作、画像容量に応じて古い履歴を整理し、直前の状態は保持）。切り出し後の高精細再描画は、全ページへ戻って位置がずれるのを防ぐため止めています。原本PDFを再選択する前に作業JSONを保存してください。

## DXF保存の案内

出力ボタンの直前に作業・図形数・実寸のチェックを表示し、未読込・画像のみ・未校正の理由をボタン直下へ表示します。出力可能な場合はダウンロード開始の案内と再ダウンロード用リンクを残します。Web Shareのファイル共有に対応する環境では「共有からファイルに保存」も利用できます。保存完了をアプリから確認できないため「保存しました」とは断定せず、端末の保存先を案内します。図形の編集や再読込では古いDXFの案内を無効にします。

## 寸法合わせをしない確認用DXF

「画像から変換してJwへ出力」は、未校正でも抽出・追記した線と円を現在の配置で出力します。未校正の場合は1画素＝1図面単位の確認用であり、実寸mmではありません。ファイル名は `cad-draft_UNSCALED_REVIEW.dxf` とし、図面内にもSCALE_NOTEレイヤーでUNSCALEDの注記を追加します。アプリ内の縮尺設定は変更しません。Jw_cadで寸法を確認・補正するまでは積算や長さの根拠へ使わないでください。

既に校正している場合は、このボタンでも実寸係数を保持して出力します。従来の「実寸を合わせたDXFを保存」は引き続き実寸設定が必要です。どちらも原本画像・未変換の文字・曲線をそのまま埋め込む機能ではありません。JWW直出力やiPadからPC上のJw_cadを自動起動する機能ではなく、保存DXFをPCのJw_cadで読み込みます。

## 編集後の自動保存と再開

図面の表示、画像だけの切り出し、加筆・削除・レイヤー変更、縮尺、囲みを同じブラウザの専用IndexedDBへ保存します。約1秒の操作停止後に保存し、保存待ち・保存中・保存済み・保存失敗を画面上部に表示します。「この端末に保存」で即時保存もできます。PDFの別ページや別ファイルは別の作業として保存し、端末内の作業一覧から再開します。原本PDFの元ファイルや他アプリの記録は変更しません。

「ファイルにも保存（JSON）」は編集済みの最新状態をダウンロードします。日時付きファイル名と直接ダウンロードリンクを用意し、ファイル共有に対応する環境では共有から保存できます。ダウンロードの開始と保存完了は別なので、端末内保存の成功だけを「保存済み」と表示します。ファイルが受け取れたかは保存先で確認してください。

元PDF全体ではなく現在のページ画像・図形・レイヤー・縮尺を保存します。編集のundo履歴と元PDFの別ページは再開データには含みません。ブラウザのデータ消去・プライベートブラウズ・容量不足などに備えJSONも保管してください。旧版でまだファイル保存されていないタブ内の作業を、新版が自動で回収する機能はありません。旧画面を閉じずにJSON保存を試すか、別タブの新版で元PDFを開いてください。

`node tests/autosave.cjs` で画像のみの保存、加筆保存、再読込からの再開、JSONダウンロード、他アプリの記録保持、保存失敗での前データ保持と再試行を検証します。

## 画像だけの状態からJwへ出力

「画像から変換してJwへ出力」は図形0個の場合に直線抽出から続けて実行します。通常のしきい値で0本なら薄い線として再試行します。取り出した候補は未分類で保存し、原本との照合が必要です。既に加筆・編集した図形が1個でもある場合は自動で再抽出せず、その内容を出力します。

画像を非同期で処理した後は、iPadのユーザー操作制約に備えて自動ダウンロードを前提にせず、押したボタンの直下に「DXFファイルを保存する」リンクを表示します。リンクまたは対応環境の共有ボタンを利用してください。0本のままなら空のDXFを出力せず設定の見直しを案内します。文字・斜線・曲線や原本画像の全体がそのままCADになるものではありません。JWW直接出力は未対応、DXFをPCのJw_cadで開いてJWWへ保存します。

`node tests/auto-export.cjs` は画像だけからの変換、薄い線の再試行、変換後の直接保存リンク、編集済み図形を壊さない出力を検証します。

## 重複・近接した抽出線の整理

抽出時は「抽出時に重複・近接線を整理」が既定でオン。まとめる間隔は1/2/4画素から選びます。平行で重なりの大きい直線をまとめ、原本画像の線間が白い場合は別の線として残す判定を入れています。細い壁や密集した線を完全に意味判別する処理ではないため原図との照合は必要です。間隔0の内部処理は無整理、既定の接続ギャップは0で、破線の隙間を自動で埋めません。

「今の未分類線を整理」は未分類の水平・垂直線だけを対象にし、分類済み図形・円・斜線は保持します。線数の前後を表示します。整理前の抽出をJSON/端末内保存にも保持し、「整理前の抽出へ戻す」で復元できます。この復元は抽出後の加筆・分類も戻すため確認を出し、直前の編集へはundoで戻せます。切り出し・解像度変更では座標系の違う整理前データを無効にします。

`node tests/cleanup.cjs` は原本画像による判定、分類済みの円の保持、整理前データを含む保存と再読込、復元・undoを検証します。
