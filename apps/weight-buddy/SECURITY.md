# 記録の保護

AES-256-GCM、ランダム16byteソルト・12byte IV、PBKDF2-SHA256 600000回。鍵は非抽出でメモリ内に保持し、パスフレーズを保存・送信しません。端末内保存・取り込み前復元用コピー・バックアップは用途別の認証情報で暗号化します。16文字以上・6種類以上の文字を要求します。

5分無操作、または画面を離れて30秒以上で再ロック。未保存入力は破棄します。CSPのスクリプト・スタイルハッシュ、外部通信制限、枠内表示拒否、入力検証、HTMLエスケープ、依存ファイルとオフライン資産のSHA256検証を実装。外部解析・広告・データAPIは使いません。Excelは端末内で読み取り、数式は実行しません。

配信サーバーには公開プログラムだけを置き、個人データを含めません。公開プログラムを改ざんできる攻撃者や、感染した端末・ブラウザ拡張、解除中の画面閲覧まで完全に防ぐことはできません。端末ロックと更新、GitHubの二要素認証・アカウント保護も必要です。サーバー側の完全な通信ヘッダー制御はGitHub Pagesではできません。パスフレーズの再発行・復旧機能はありません。
