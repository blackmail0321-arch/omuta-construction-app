## Ver0.13の追加更新

仮反映で選んだ建設物価／建築コスト情報の単価を代価表D／E列から数式参照します。材料価格の雑材・労務・丸め式は同梱Excelから読み取り、明細行に合わせてセル参照を展開します。刊行物価格の加算や比較価格の自動採用は行いません。通常建退共は30日、予算率の初期値は20％（変更可）。既存Ver0.9は保全しています。

ビルド：`cd apps/integrated-v0.13 && python3 integrated/build.py`。生成結果は `integrated/index.html` です。配布入口を更新する際は同ファイルをフォルダ直下の `index.html` へコピーします。

最新の追加指示：刊行物を材料価格として仮反映した明細では、S上段を有効3桁の中間単価、S下段を刊行物単価＋中間単価のROUNDDOWNにします。T上段は合算式の桁数です。以前の「加算しない」方針よりこの追加指示を優先します。

## 2026年10月15日の更新（以前の端数処理説明を置換）

「別候補・単価を照合」をオレンジ色の開閉操作に変更し、開閉案内とキーボードフォーカスを追加しました。
組立単価のJ下段は `INT(MIN(F下段:H下段)*I下段/100)+D上段`。
刊行物価格とメーカー等の元価格を分離し、D上段は数値入力欄（初期0）としました。刊行物の出典・掲載箇所は採用根拠シートに保持します。
S上段はR下段を有効3桁へ切捨て。刊行物加算後のS下段は `ROUNDDOWN((D/E下段+S上段)/T上段,0)*T上段` で、Tは桁数ではなく円単位です。100なら100円未満切捨て。
例：メーカー価格6,800円×36%=2,448円、雑材料5%=122円、中間単価2,570円。刊行物28,800円との合算31,370円は100円未満切捨てで31,300円になります。
新しい計算版を読み込むと最終確認を解除します。入力値は保持しますが、更新前に必ずバックアップし、再計算後の金額を確認してください。

検証：アプリをポート8013でHTTP配信し `node tests/publication-rounding.cjs` を実行。その出力ディレクトリを `python3 tests/check-publication-workbooks.py <出力ディレクトリ>` へ渡します。PlaywrightとChromiumが必要です。刊行物2種類×設計/予算、行32の数式・金額・内訳連動、端数処理1/10/100/1000、データ保持と最終確認解除、キーボード開閉を検証します。Excel本体での再計算は別途必要です。

## 明細別数式・入力確認の追加更新

計算式は固定のJ32/S32ではなく、各明細の上下2行へ対応します。メーカー価格・労務単価の異なる行6/8/10/32で、J・S列と内訳への連動を検証しています。
選択欄を青色にし、採用・保留保存・対象外・仮反映・工期設定・契約条件・提出状態・単価登録などの決定時に、入力漏れや未確認を赤色と文言で表示します。最初の不足欄へ移動し、訂正後はエラーを解除します。任意の出典掲載箇所は必須にせず、単価0円も許容します。最終確認できない理由も画面に表示します。入力内容は消去しません。
回帰確認：`node tests/form-feedback.cjs`（Playwright/Chromium、ポート8013の配信が必要）。

## 共有機能の開発検証

Docker・Python3・Node・Playwright/Chromiumがある環境で、`python3 tests/shared-db-test.py` は実PostgreSQLのRLS/権限/競合/期限を検証します。`python3 tests/run-shared-integration.py` は一時PostgreSQL/PostgRESTを起動してブラウザからPC→iPad/スマホの流れを検証し、テストサービスを削除します。Supabase Authだけはテスト代替で、本物のSupabase接続・実端末確認は別途必要です。`python3 tests/shared-config-test.py` は公開用設定と閲覧専用配信物の分離を検証します。テスト用認証サーバーや固定テストパスワードを本番へ配信しないでください。
