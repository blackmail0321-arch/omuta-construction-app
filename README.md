# 設備工事アプリ Codex移行パッケージ Ver1.0

作成日：2026年10月13日。提出書類管理と予算・積算・設計の両方を引き継ぐためのパッケージです。

## 最初に行うこと

1. ZIPをPC上で展開し、このフォルダ全体をCodexの作業対象にしてください。GitHubを利用する場合は非公開リポジトリへ登録します。
2. `CODEX_START.md` の指示文をCodexへ渡してください。
3. 現在の更新版は `apps/integrated-v0.13/index.html` です。現在のブラウザ試作を確認できます。
4. 開発は更新版フォルダの `integrated/` 内の分割コードを確認して進めます。既存原本は `originals/` に保管しています。
5. 現在使用しているアプリで「作業バックアップ」を保存し、移行時に別途渡してください。端末内の最新入力データはこのZIPへ自動収録されていません。

## Ver0.13の追加更新

仮反映で選んだ建設物価／建築コスト情報の単価を代価表D／E列から数式参照します。材料価格の雑材・労務・丸め式は同梱Excelから読み取り、明細行に合わせてセル参照を展開します。刊行物価格の加算や比較価格の自動採用は行いません。通常建退共は30日、予算率の初期値は20％（変更可）。既存Ver0.9は保全しています。

ビルド：`cd apps/integrated-v0.13 && python3 integrated/build.py`。生成結果は `integrated/index.html` です。配布入口を更新する際は同ファイルをフォルダ直下の `index.html` へコピーします。

最新の追加指示：刊行物を材料価格として仮反映した明細では、S上段を有効3桁の中間単価、S下段を刊行物単価＋中間単価のROUNDDOWNにします。T上段は合算式の桁数です。以前の「加算しない」方針よりこの追加指示を優先します。
