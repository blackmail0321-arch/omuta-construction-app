# 設備工事アプリ Codex移行パッケージ Ver1.0

作成日：2026年10月13日。提出書類管理と予算・積算・設計の両方を引き継ぐためのパッケージです。

## 最初に行うこと

1. ZIPをPC上で展開し、このフォルダ全体をCodexの作業対象にしてください。GitHubを利用する場合は非公開リポジトリへ登録します。
2. `CODEX_START.md` の指示文をCodexへ渡してください。
3. 統合の第一候補は `apps/integrated-v0.9/index.html` です。現在のブラウザ試作を確認できます。
4. 開発は同フォルダの `integrated/` 内の分割コードを確認して進めます。既存原本は `originals/` に保管しています。
5. 現在使用しているアプリで「作業バックアップ」を保存し、移行時に別途渡してください。端末内の最新入力データはこのZIPへ自動収録されていません。

## 収録内容と位置付け

|フォルダ|位置付け|
|---|---|
|apps/integrated-v0.9|統合の土台候補。刊行物単価欄・入力改善を含む|
|apps/estimate-stage5.59|2026年10月9日保存の実資料積算・採用連動版。元コード、資料抽出データ、ビルド処理を収録|
|apps/estimate-stage5.69|別系統の設計書製作アプリ2。資料保存・根拠紐付け版と復帰用ZIPを収録|
|apps/submissions-v0.2|提出書類単独版。HTMLと操作マニュアル|
|originals|取得したZIP、仕様書、提出書類PDF、Excel業務試作の原本|
|docs|移行仕様、残課題、受入チェック、既存Word仕様のテキスト|

版番号だけで最新版を決定しないでください。Stage5.69は10月2日、実資料版Stage5.59は10月9日の保存です。統合Ver0.9との機能差分を確認して採用します。
